# 📱 message-printer
LINEやショートメール（SMS/iMessage）のやり取りを、綺麗で読みやすいレイアウトのまま印刷用ページとして出力するWebツール群です。

---

## 💡 開発のきっかけ

**「ショートメールやLINEのやり取りをそのまま印刷したい」** というご依頼がきっかけで開発しました。

スマートフォンの画面をそのままスクリーンショットを撮って印刷しようとすると、
* 画面の枠やステータスバーが入ってします
* 長いやり取りだと何枚もスクショを撮影・印刷しなければならず手間がかかる
* 文字の大きさやレイアウトが揃わず読みづらい

といった課題がありました。

そこで、テキストを入力するだけで**ブラウザ上で見やすいチャット画面（LINE風・SMS風）を再現し、そのままA4用紙などに綺麗に印刷（PDF化）できるツール**を構築しました。

---

## 🚀 主な機能・特徴

- **複数日トーク対応**: `#2026/10/03` のように日付ヘッダーを挟むことで、数日間にわたる会話履歴を時系列で綺麗にレイアウト。
- **シンプルな記号入力**:
  - `#` : 日付ヘッダー
  - `<` : 相手のメッセージ（左側）
  - `>` : 自分のメッセージ（右側）
- **選べる2つのデザインスタイル**: LINE風（グリーン／ブルー）と、iOS/ショートメール風（ブルー／グレー）のテーマを用意。
- **印刷最適化（@media print）**: 印刷時には不要な入力フォームやボタンを自動で非表示し、吹き出しや日付の途中でページが不自然に切れないよう調整済み。
